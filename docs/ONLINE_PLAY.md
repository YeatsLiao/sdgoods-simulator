# 联网试玩

GitHub Pages 托管页面和模拟器。访客在浏览器中运行固件，固件需要通过独立的 HTTPS/WSS 服务访问电台或语音后端。现有 Python 中继只用于本机回环。

## 验收顺序

1. Radio 优先。核对可公开分发的 BIN 和电台列表，实测其 DNS、音频流目标及重定向。公开服务按示例限制出口域名、端口、连接数和会话时长。用没有启动本地服务的浏览器验收，确认能载入电台并听到声音。
2. 小智随后。确认固件的设备绑定和服务端演示账号，再验收麦克风授权和完整对话。演示账号的凭据留在服务端。

当前公开站点仍是离线 WASM 版。上线联网试玩需要一个有部署权限的公开 HTTPS/WSS 服务环境，以及可公开分发的联网示例。当前仓库只配置了 GitHub Pages。现阶段联网测试请使用本地完整版。
