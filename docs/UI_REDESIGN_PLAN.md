# 次元屏工作台重构计划

日期：2026-11-20；实物对齐更新：2026-11-22。状态：本轮实现完成；完整人工回归待补充，见执行记录。

## 目标与边界

主要用户是在本地反复调试 BIN 的次元屏开发者。核心流程为打开文件、看见首帧、操作设备、按需查看调试信息。保留示例、URL、最近使用、两种运行方式、声音、Flash、截图、录屏和检查器。市场接入继续暂缓；隐藏的槽能力保持兼容。

沿用原生 ES 模块、Python 标准库和 DeviceSession。保留当前工作区已有修改，不提交、不发布。界面改造不改 ESP-EMU 协议、触摸换算、渲染调度和音频处理算法。

## 设计依据与方向

采用 [Anthropic frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design) 的先规划、审视、实现、截图复核流程。上游会变化，实施依据为 2026-11-20 阅读的版本。

方向是清晰的设备实验台：浅色工具界面包围真实圆屏，圆屏及其机身是视觉中心。导入与观察分区明确，当前状态与下一步操作始终可见。

- 画布 `#F3F5F8`，面板 `#FFFFFF`，正文 `#182338`，辅助文字 `#526078`，操作蓝 `#2359D8`；设备采用黑色玻璃面和银色金属边框、侧键（2026-11-22 按实物更新）。错误、警告和成功另用语义色，颜色同时配文字。
- 中文采用本机 Microsoft YaHei UI / PingFang SC，正文 16px，常用控件 14px，元信息最小 12px。十六进制和日志采用等宽字体。
- 桌面布局为顶部状态栏、左侧工具导航、中间设备、右侧可收起的工作面板。文字左对齐，设备和设备操作居中。窄屏改为设备在上、面板在下，允许自然滚动。
- 首屏突出一个「打开本地 BIN」按钮，示例作为辅助入口，URL 导入折叠。运行后收起导入面板，留出观察空间；工具导航随时重新打开面板。
- 不显示市场占位卡片，不自动弹技术说明，不以模糊遮罩阻挡上手。数据清除进入明确的数据管理区域并确认。
- 加载反馈覆盖读取、准备、启动、等待首帧、运行和失败。显示当前状态时不能让音频格式报文覆盖运行进度。

设计复核：浅色不是通用营销页模板，视觉中心是可操作的真实设备；不添加大标题宣传区、统一卡片墙、装饰渐变或无意义编号。机身采用实体轮廓，工具区域保持平整。

1. 新会话无需阅读说明即可找到本地文件入口；可取消文件选择；同一个文件可重新选择。
2. 拖放文件和文件选择走同一校验路径；错误文件反馈原因并保留重试入口；切换固件不会误清数据。
3. 本机和 WASM 均能显示真实示例首帧。启动、首帧等待、运行、失败可区分；运行后可重新打开固件面板。

### 2026-11-22 按风格预览图做机身材质升级

用户给的预览图（暖白 + 大标题 + 立体金属圆机）与实现的差距集中在机身：单层线性渐变的细银边、死黑玻璃、几乎不可见的侧键，看起来像贴纸而不是实体吧唧。本轮采用**材质升级、轮廓不变**：正面剪影、单条金属边、内嵌侧键这三条 §8 约束保留，只把明暗、厚度和落地感做出来。

- 金属壳：`--bezel-pad` 由固定 9px 改为 3.2% 比例值（572px 桌面 ≈18px、322px 手机 ≈10px），`conic-gradient(from 315deg)` 出左上受光、右下暗面与底部回光，色值按实物的灰银而非宣传图的亮银。
- 高光：`::before` 斜向高光带用 `mask` 只保留外圈，中心完全透明，不遮画面也不参与命中测试。
- 玻璃：`#screen` 去边框，黑玻璃圈改由 `box-shadow: 0 0 0 4px` 的 spread 画在金属内侧——不占布局，`getBoundingClientRect()` 仍是 360×360 触摸换算的基准。
- 落地感：`::after` 椭圆接触阴影（`z-index:-1`，落在机身自己的层叠上下文里）+ 双层外投影。
- 侧键：可见部分从 3×22px 细线改成暗槽（8×38px）内的短键（6×34px，手机 5×26px），中心落在金属带中线偏内；键体色取自机身 conic 在 2 点位的色域（约 #97a0a5），不用高亮白——初版把 disabled 态画成 #dfe4e6，比周围亮两档，看着像浮在边上的白条。悬停提亮并描蓝、按下沿半径方向下沉 1px；说明文字用 `.device-stage:has(.side-key:hover)` 的 CSS tooltip，`(hover:none)` 下不出现，不做自动弹窗。
- 待机画面：`.run-cta` 在 idle 给同心暗纹 + 呼吸微光，preparing/starting/waiting 给旋转细弧；running 时该层整体隐藏，不碰固件画面。
- 页面质感：`.device-stage` 560→572px 补偿加厚的边框，首屏正文与机身间距收紧，控制栏图标按钮统一 48px 方形并补悬停底面。
