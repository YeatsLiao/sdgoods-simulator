# 使用指南

## 打开固件

点击「打开 BIN」或拖入 ESP32-S3 固件。整机 BIN 应包含引导和分区数据，兼容的 SDGOODS 纯 app 包会自动配上平台引导层。出现型号错误时，请检查 BIN 的目标是否为 ESP32-S3。

本机加速使用 Linux 运行环境，Windows 下需要 Ubuntu WSL。浏览器模式使用 WASM，复杂固件可能较慢。

## 操作和数据

- 圆屏支持点按、长按和拖动。右上侧键和空格把按键交给固件，动作取决于固件。
- 重启保留设置和进度。「开发工具 → 设置 → 清除运行数据」会重置当前固件。移除最近记录只移除列表项。
- 设备下方提供截图和录屏。「开发工具 → 声音」可调音量、静音和麦克风。麦克风需主动授权。
- 静态网页版读取本地 BIN，并将固件数据保存在当前站点的浏览器存储中。换浏览器或清除站点数据会失去该站点的本地进度。

## 常见问题

- **黑屏或启动失败**。检查运行状态，在「开发工具 → 日志」查看启动信息，再用已知可运行的 BIN 对照。
- **没声音或声音断续**。先检查静音和音量。复杂游戏可以切换本机加速，并在相同场景对照。
- **卡在配网界面**。本地完整版使用模拟 Wi-Fi，由固件连入 `myssid`，密码为 `mypassword`。是否能进入应用取决于固件的配网实现。静态网页版适合离线应用，设备 SoftAP 配网页、原生加速和网络中继需本地服务或真机环境。
- **需要 BLE、NFC 或复核时序**。使用真机。模拟器的画面、声音、性能和时序可能与实物有差异。
