谷仓次元屏

欢迎使用模拟器

在浏览器中运行 ESP32-S3 次元屏固件。固件只在本机加载与缓存，不会上传到服务器。

本机加速

在 x86-64 Linux 或 Windows 的 Ubuntu WSL 中运行原生模拟器，帧率更高、输入延迟更低。状态：检测中

浏览器

无需安装，直接在网页内运行。性能受浏览器限制，重负载玩法建议使用本机加速。

扬声器在开始运行后启用；麦克风需要在音频面板手动开启，并由浏览器请求授权。

运行方式、重启和清除数据可以在顶部与底部控制栏调整。
